# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please read the full text at the link above. In short: be respectful, be constructive, and help us maintain a welcoming community for everyone.

## Reporting

If you experience or witness unacceptable behavior, please open a private report via [GitHub](https://github.com/BonzTM/nms-expeditions-online/security/advisories/new) or contact the maintainer directly.
